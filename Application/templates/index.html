ℹ About the SH-WFS Pipeline

Shack–Hartmann Wavefront Sensor — High-Performance Diagnostic Framework

Overview

This dashboard demonstrates a modular Shack–Hartmann Wavefront Sensor (SH-WFS) processing pipeline. It simulates atmospheric turbulence, captures synthetic subaperture images, estimates wavefront slopes via center-of-mass, and reconstructs the phase using a learned reconstructor matrix.

Pipeline Stages

  1. Atmospheric Phase Simulation — Synthetic turbulence injected as spot displacements on a 4×4 lenslet grid (64×64 px detector).
  2. Windowed Center-of-Mass — Subaperture gradient extraction with background thresholding.
  3. Phase Reconstruction — Linear reconstructor matrix mapping slopes to actuator commands.
  4. Decoupled Mirror Control — Pseudo-inverse control matrix for DM stroke linearization.
  5. PINN Residual Correction — Edge-case non-linearity compensation via tanh-activated neural inference.
  6. PSF Computation — Far-field diffraction pattern derived from the reconstructed phase.
  7. Zernike Decomposition — Modal analysis identifying dominant aberrations (tip, tilt, defocus, etc.).
